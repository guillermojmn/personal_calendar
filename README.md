# Mi Calendario

Calendario personal para apuntar citas, tareas, recordatorios y cualquier cosa que tengas.

## Cómo usarlo

Abre `index.html` con doble clic (Chrome, Edge o Firefox). No necesita instalación ni internet.

- **Clic** en un día → ves lo que tienes ese día en el panel derecho.
- **Doble clic** en un día o botón **+ Nuevo** → apuntar algo.
- **Clic** en cualquier elemento → editarlo o eliminarlo.
- Las **tareas** tienen casilla para marcarlas como hechas.
- Se pueden **repetir** cosas cada día, semana, mes o año (cumpleaños, clases…).
- **Buscar** filtra por título, notas o lugar.
- Atajos: `←` / `→` cambiar de mes, `T` ir a hoy, `N` nuevo.

## Dónde se guardan los datos

Los datos se guardan **en el navegador** (localStorage) del ordenador donde lo uses. No se suben a ningún sitio ni se guardan en el repositorio.

Por eso, de vez en cuando usa el menú **⋯ → Exportar copia de seguridad**: descarga un `.json` que puedes volver a cargar con **Importar copia de seguridad** (también sirve para pasar tus datos a otro ordenador o navegador).
